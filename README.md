# Sebastian Rivera — AI Automation & Agent Systems

A responsive, static, single-page professional portfolio. No build step, tracking scripts, external dependencies, or secrets.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish using GitHub Pages

1. Create a public repository named `sebastian-portfolio` in your GitHub account.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. GitHub will show the published URL once deployment finishes. Do not assume a live URL before verifying deployment.
